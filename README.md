# SimpleCam

## Ver. 1.5.0

リアカメラを全画面でプレビューする、タッチ操作専用のブラウザアプリです。録画や静止画保存は行わず、プレビュー表示と表示範囲の調整に特化しています。

Ver. 1.5.0 では、音響コントロールと音色を拡張し、高コントラスト映像でのクリップノイズ対策、POLYモニター、ブラウザ版UIマニュアルを追加しています。

- Release: `v1.5.0`
- Changelog: [`CHANGELOG.md`](./CHANGELOG.md)
- UI manual: [`manual.html`](./manual.html)
- Audio noise investigation: [`docs/audio-noise-investigation.md`](./docs/audio-noise-investigation.md)

## Current Spec

- 全画面プレビューがそのまま撮影範囲です。
- 対応操作は `ピンチ` によるズーム、`スワイプ` によるパンです。
- ズーム倍率は `1x` から `9x` です。
- 右上の `FULL` ボタンで全画面表示に切り替えできます。
- `REAR` / `FRONT` ボタンで、対応端末のインカメラとアウトカメラを切り替えできます。
- 音響コントロールは下部の専用パネルへ常時表示し、`SND` ボタンでWebAudio APIによる合成音をON/OFFできます。初期値はOFFです。
- `MIR` ボタンで、カメラ表示を左右反転できます。初期値はOFFです。
- `ECO` ボタンで `ECO OFF` / `ECO ON` / `ECO MAX` の3段階を切り替えられます。内部描画解像度、描画更新頻度、音響解析頻度、カメラ要求設定を段階的に下げて処理負荷を抑えます。
- `UI` ボタンで、スライダーと操作ボタン群を一括で表示・非表示できます。
- `HELP` を押すと、UIマニュアルを別タブで開きます。
- 下端には映像用の `DELAY` / `CONTRAST` / `TRAIL` の3本を配置し、その上に音響用のボタンとスライダーをまとめて常時表示しています。
- `DELAY` / `CONTRAST` / `TRAIL` の初期値はすべて `0` です。
- `CONTRAST` スライダーで、暗部を黒に落とす輝度閾値を調整できます。`0` の時はOFFで、閾値以上のピクセルは輝度を持ち上げてコントラストを強調します。
- `DELAY` スライダーで、30枚固定リングバッファを使った遅延表示量を調整できます。`0` の時は遅延なしです。
- `TRAIL` スライダーで、直前の描画フレームを減衰させながら最新フレームと合成する残像量を調整できます。低い値から効き始めるようにカーブを調整しています。
- フルスクリーン解除後もスライダーが見えるように、`visualViewport` の高さに合わせてレイアウトを再計算します。
- 操作説明テキストは常時表示せず、エラー時のみメッセージを表示します。

## Filters

- `CONTRAST`: 輝度がスライダー値を下回るピクセルを黒に落とし、それ以外のピクセルは Shader 内で正規化して明るさとコントラストを持ち上げます。
- `DELAY`: 30枚固定のリングバッファへカメラフレームを蓄積し、スライダー値に応じて過去フレームを参照します。
- `TRAIL`: 前回の描画結果を ping-pong framebuffer で保持し、古いフレームを減衰させたうえで新しいフレームとブレンドします。
- 表示経路は WebGL canvas に統一しており、`0 -> 1` でプレビューが別系統へ切り替わるジャンプを避けています。

## Performance Behavior

- `DELAY = 0`: リングバッファへのフレーム保存を停止し、遅延テクスチャを `1 x 1` に縮小します。
- `TRAIL = 0`: ping-pong framebuffer と追加の画面描画を省略します。
- `CONTRAST = 0`: Shader内のコントラスト処理を省略します。表示経路を統一するため、WebGLへの映像転送と基本描画は継続します。
- `SND OFF`: 画像解析を停止し、AudioContextを休止します。
- `DELAY` / `CONTRAST` / `TRAIL` がすべて `0` の場合も、輝度ジャンプを避けるためWebGLの基本描画は継続します。

## Economy Mode

- `ECO OFF`: WebGL canvas を等倍、描画上限を `60fps`、カメラを `1920 x 1080` / `60fps` 優先で動作させます。
- `ECO ON`: WebGL canvas を `0.6x`、描画上限を `24fps`、音響解析を約 `10fps`、カメラを `1280 x 720` / `24fps` 優先にします。
- `ECO MAX`: WebGL canvas を `0.3x`、描画上限を `12fps`、音響解析を約 `5fps`、カメラを `960 x 540` / `12fps` 優先にします。
- カメラが指定値に対応しない場合は、ブラウザが利用可能な設定を選びます。
- 対応ブラウザでは `requestVideoFrameCallback` を使い、新しいカメラフレームが届いた時だけ描画処理を起動します。
- DELAYリングバッファは表示比率にクロップした低解像度GPUテクスチャを使い、保存時刻を基準に遅延フレームを選択します。
- SND OFF時とページがバックグラウンドに移った時は音響処理を休止し、バックグラウンドではカメラトラックとWebGL描画も一時停止します。

## Audio

- `SND`: デフォルトはOFFです。ONにすると、実際に表示されている WebGL canvas の描画フレームから合成音を生成します。
- 音響パネルには `SND` / `ENV` / `RGB` / `TONE` と `THRESH` / `REL` / `OCT` / `POLY` / `GAIN` / `SAT` をまとめて常時表示します。全体の `UI` ボタンでは他の操作UIと一緒に非表示にできます。
- 解析フレームは、画面上で指定した矩形領域を `64 x 36` に低解像度化したものです。
- 音量は解析フレーム内の最大輝度で決まります。黒を `0%`、白を `100%` として扱います。
- 音程はRGBプレーンを分解し、低彩度ピクセルを除外したうえで、各プレーンの値を4段階に分類して `ド` / `ミ` / `ソ` / `シ` に割り当てます。
- 初期状態では `B` が1オクターブ下、`G` が中央、`R` が1オクターブ上を担当します。`RGB` ボタンで低音・中央・高音の担当を `BGR` / `GRB` / `RBG` の順にローテーションできます。
- `TONE` ボタンで `SIN` / `TRI` / `FM 1:1` / `FM 3:1` / `FM 3:2` / `FM SQRT2` の6音色を順番に切り替えられます。`TRI` と各FM音色は、彩度と該当レンジのピクセル支配率を倍音量へ反映します。
- `THRESH` は発音トリガーの変化量閾値、`REL` はリリース時間、`OCT` は基準ピッチのオクターブシフトを調整します。
- `POLY` は画像内で支配率の高い音から選び、最大同時発音数を `1` から `12` の範囲で制限します。
- `GAIN` は `0` で従来音量、`100` で従来の10倍になるようコンプレッサー入力を調整します。
- 音量ゲインカーブは従来初期値の指数 `1.35` に固定しています。`SAT` は `0` で従来どおり高彩度を強く評価し、`100` で評価を反転して低彩度を強く評価します。中間値では両者を線形補間します。
- 発音開始と停止を短いランプで平滑化し、DC除去、コンプレッサー、2倍オーバーサンプリングのソフトクリップ、最終段のヘッドルーム確保によってクリップノイズを抑えます。
- 高ゲイン時はWebAudio標準のコンプレッサーをソフトニーで早めに効かせ、低負荷のソフトクリップで瞬間的なピークを保護します。
- ENV ONでは発音時の輝度を各音のピーク音量へ反映し、その後はRELで減衰させます。無音フレームでは再トリガーせず、画面の暗転で余韻を短く切りません。
- AudioContextはbalanced latencyを要求し、通常モードの音響解析を最大30fpsに抑えます。FM高音域ではサンプルレートに合わせて変調量を制限します。
- FM音色は、変調周波数比と最大変調指数を `1:1 / 3.0`、`3:1 / 3.5`、`3:2 / 2.5`、`SQRT2:1 / 2.0` に設定しています。LFOは使わず、彩度と画素占有率に応じて正弦波からそれぞれ異なるFM倍音へ変化します。
- `POLY MONITOR` は12音の選択状態をバーで表示し、現在の選択音数と `POLY` の設定上限を数値で示します。更新は最大15fpsです。
- エンベロープの再トリガーは最短80ms間隔です。進行中の音量カーブの現在値から再アタックし、周波数とFM量も滑らかに更新します。`THRESH = 0`でも変化がないフレームでは再発音しません。
- 音量、音程、倍音、発音トリガーの画像解析は、画面上の点線矩形内だけを対象にします。初期範囲は画面中央の60%です。
- 点線矩形の左上と右下にあるハンドルをドラッグして、解析範囲と大きさを変更できます。ズーム、パン、左右反転を反映した実際の表示位置から解析します。

## Supported Devices

- iPad
- Android タブレット / Android スマートフォン

タッチ端末での利用を前提としており、マウス操作は対象外です。

## Usage

1. HTTPS または `localhost` でアプリを開きます。
2. ブラウザのカメラ権限を許可します。
3. リアカメラの全画面プレビューを確認します。
4. ピンチでズーム、スワイプで表示中心を移動します。
5. 点線矩形の左上・右下ハンドルをドラッグして、音響解析領域を調整します。
6. 必要に応じて音響パネル内の設定と、`MIR` / `ECO` / `REAR` / `FRONT` / `CONTRAST` / `DELAY` / `TRAIL` / `FULL` を調整します。

## Files

- `index.html`: UI 構造
- `manual.html`: ブラウザで参照できるUI操作マニュアル
- `manual.css`: UI操作マニュアル専用スタイル
- `styles.css`: 全画面表示とオーバーレイ UI
- `app.js`: カメラ起動、カメラ切り替え、ズーム、パン、全画面切り替え、WebGL Shader フィルタ描画、WebAudio 合成
- `audio-automation.mjs`: 再トリガー時の音量・周波数カーブの保持と更新
- `tests/`: `node --test tests/*.test.mjs`で実行する音響カーブ・トリガー判定の回帰テスト
- `scripts/investigate-audio.mjs`: 明暗変化、ENV余韻、FM高域制限を数値確認する診断スクリプト
- `CHANGELOG.md`: リリースごとの変更履歴
- `.github/workflows/deploy-pages.yml`: GitHub Pages 自動デプロイ

## Deployment

`main` ブランチへ push すると GitHub Pages に自動デプロイされます。

- Repository: `https://github.com/kobashi/simplecam`
- Publish URL: `https://kobashi.github.io/simplecam/`

GitHub 側では `Settings > Pages > Build and deployment > Source` を `GitHub Actions` に設定します。

## Notes

- カメラ利用にはセキュアコンテキストが必要です。`https://` または `localhost` でアクセスしてください。
- 初期カメラは `facingMode: environment` を優先して取得します。
- ズームとパンはブラウザ上の表示変形として実装しています。
- WebAudio はブラウザの自動再生制限に合わせて、`SND` ボタン操作後に開始します。
- 端末やブラウザによって、全画面 API の挙動や見た目が一部異なることがあります。
