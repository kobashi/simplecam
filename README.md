# SimpleCam

## Ver. 1.2

リアカメラを全画面でプレビューする、タッチ操作専用のブラウザアプリです。録画や静止画保存は行わず、プレビュー表示と表示範囲の調整に特化しています。

Ver. 1.2 では WebGL Shader による高速な表示フィルタに加えて、前後カメラ切り替え、描画フレームから生成する WebAudio 合成音、操作負荷を抑えるエコノミーモードを追加しています。

## Current Spec

- 全画面プレビューがそのまま撮影範囲です。
- 対応操作は `ピンチ` によるズーム、`スワイプ` によるパンです。
- ズーム倍率は `1x` から `9x` です。
- 右上の `FULL` ボタンで全画面表示に切り替えできます。
- `REAR` / `FRONT` ボタンで、対応端末のインカメラとアウトカメラを切り替えできます。
- `SND` ボタンで、WebAudio API による合成音をON/OFFできます。初期値はOFFです。
- `ECO` ボタンで `ECO OFF` / `ECO ON` / `ECO MAX` の3段階を切り替えられます。内部描画解像度、描画更新頻度、音響解析頻度、カメラ要求設定を段階的に下げて処理負荷を抑えます。
- `UI` ボタンで、スライダーと操作ボタン群を一括で表示・非表示できます。
- 下端に `DELAY` / `CONTRAST` / `TRAIL` / `THRESH` / `REL` / `OCT` の6本スライダーを横並びで配置しています。
- `DELAY` / `CONTRAST` / `TRAIL` の初期値はすべて `0` です。
- `CONTRAST` スライダーで、暗部を黒に落とす輝度閾値を調整できます。`0` の時はOFFで、閾値以上のピクセルは輝度を持ち上げてコントラストを強調します。
- `DELAY` スライダーで、30枚固定リングバッファを使った遅延表示量を調整できます。`0` の時は遅延なしです。
- `TRAIL` スライダーで、直前の描画フレームを減衰させながら最新フレームと合成する残像量を調整できます。低い値から効き始めるようにカーブを調整しています。
- フルスクリーン解除後もスライダーが見えるように、`visualViewport` の高さに合わせてレイアウトを再計算します。
- 操作説明テキストは常時表示せず、エラー時のみメッセージを表示します。

## Filters

- `CONTRAST`: 輝度がスライダー値を下回るピクセルを黒に落とし、それ以外のピクセルは Shader 内で正規化して明るさとコントラストを持ち上げます。
- `DELAY`: 30枚固定のリングバッファへカメラフレームを蓄積し、スライダー値に応じて過去フレームを参照します。
- `TRAIL`: 前回の描画結果を ping-pong framebuffer で保持し、古いフレームを減衰させたうえで新しいフレームとブレンドします。
- 表示経路は WebGL canvas に統一しており、`0 -> 1` でプレビューが別系統へ切り替わるジャンプを避けています。

## Economy Mode

- `ECO OFF`: WebGL canvas を等倍、描画上限を `60fps`、カメラを `1920 x 1080` / `60fps` 優先で動作させます。
- `ECO ON`: WebGL canvas を `0.6x`、描画上限を `24fps`、音響解析を約 `10fps`、カメラを `1280 x 720` / `24fps` 優先にします。
- `ECO MAX`: WebGL canvas を `0.3x`、描画上限を `12fps`、音響解析を約 `5fps`、カメラを `960 x 540` / `12fps` 優先にします。
- カメラが指定値に対応しない場合は、ブラウザが利用可能な設定を選びます。
- 対応ブラウザでは `requestVideoFrameCallback` を使い、新しいカメラフレームが届いた時だけ描画処理を起動します。
- DELAYリングバッファは表示比率にクロップした低解像度GPUテクスチャを使い、保存時刻を基準に遅延フレームを選択します。
- SND OFF時とページがバックグラウンドに移った時は音響処理を休止し、バックグラウンドではカメラトラックとWebGL描画も一時停止します。

## Audio

- `SND`: デフォルトはOFFです。ONにすると、実際に表示されている WebGL canvas の描画フレームから合成音を生成します。
- 解析フレームは画面全域を `64 x 36` に低解像度化したものです。
- 音量は解析フレーム内の最大輝度で決まります。黒を `0%`、白を `100%` として扱います。
- 音程はRGBプレーンを分解し、低彩度ピクセルを除外したうえで、各プレーンの値を4段階に分類して `ド` / `ミ` / `ソ` / `シ` に割り当てます。
- `B` は1オクターブ下、`G` は中央、`R` は1オクターブ上を担当し、最大で4音程 x 3オクターブの12音が同時に鳴ります。
- 音色はFM合成で生成します。彩度が高く、該当レンジのピクセル支配率が高いほど倍音成分が強くなります。
- `THRESH` は発音トリガーの変化量閾値、`REL` はリリース時間、`OCT` は基準ピッチのオクターブシフトを調整します。

## Supported Devices

- iPad
- Android タブレット / Android スマートフォン

タッチ端末での利用を前提としており、マウス操作は対象外です。

## Usage

1. HTTPS または `localhost` でアプリを開きます。
2. ブラウザのカメラ権限を許可します。
3. リアカメラの全画面プレビューを確認します。
4. ピンチでズーム、スワイプで表示中心を移動します。
5. 必要に応じて `SND` / `ENV` / `ECO` / `REAR` / `FRONT` / `CONTRAST` / `DELAY` / `TRAIL` / `FULL` を調整します。

## Files

- `index.html`: UI 構造
- `styles.css`: 全画面表示とオーバーレイ UI
- `app.js`: カメラ起動、カメラ切り替え、ズーム、パン、全画面切り替え、WebGL Shader フィルタ描画、WebAudio 合成
- `.github/workflows/deploy-pages.yml`: GitHub Pages 自動デプロイ

## Deployment

`main` ブランチへ push すると GitHub Pages に自動デプロイされます。

- Repository: `https://github.com/kobashi/simplecam`
- Publish URL: `https://kobashi.github.io/simplecam/`

GitHub 側では `Settings > Pages > Build and deployment > Source` を `GitHub Actions` に設定します。

## Notes

- カメラ利用にはセキュアコンテキストが必要です。`https://` または `localhost` でアクセスしてください。
- 初期カメラは `facingMode: environment` を優先して取得します。
- ズームとパンはブラウザ上の表示変形として実装しています。
- WebAudio はブラウザの自動再生制限に合わせて、`SND` ボタン操作後に開始します。
- 端末やブラウザによって、全画面 API の挙動や見た目が一部異なることがあります。
