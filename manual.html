UI MANUAL

映像を触り、
色を音にする。

SimpleCamの画面操作、映像エフェクト、画像連動サウンドをまとめた操作ガイドです。

01 カメラを許可 02 画角を調整 03 効果と音を選択

01

GETTING STARTED

最初の操作

カメラを許可

HTTPSでページを開き、ブラウザのカメラ使用確認を許可します。映像や音声は保存・送信しません。

画角を決める

2本指のピンチで1〜9倍にズーム。1本指のスワイプで表示位置を移動します。

音を開始

SND OFFを押してONにします。端末の音量を低めから調整してください。

02

SCREEN CONTROLS

画面上部のボタン

HELP
マニュアル

このページを別タブで開きます。

ECO
処理負荷

OFF → ON → MAXの順に切り替えます。解像度、FPS、音響解析頻度を段階的に下げます。

MIR
左右反転

カメラ映像と音響解析位置を左右反転します。

REAR
FRONT
カメラ切り替え

アウトカメラとインカメラを切り替えます。利用可能なカメラが1台の場合は表示されません。

FULL
フルスクリーン

ブラウザが対応している場合に全画面表示へ切り替えます。

UI
UI表示

右上のボタンで操作UIをまとめて表示・非表示にします。UI OFFでもこのボタンは残ります。

03

VISUAL EFFECTS

映像エフェクト

DELAY初期値 0

時間をずらす

30枚のリングバッファから過去のカメラフレームを表示します。0では遅延しません。

CONTRAST初期値 0

暗部を切る

値より暗いピクセルを黒へ落とし、それ以外の明るさとコントラストを持ち上げます。

TRAIL初期値 0

残像を残す

直前までの描画結果を減衰しながら最新フレームと合成します。値が大きいほど残像が長く残ります。

04

IMAGE TO AUDIO

音響コントロール

SND
サウンド

画像解析と合成音をON/OFFします。初期状態はOFFです。

ENV
エンベロープ

ONでは画像変化をトリガーに発音し、固定AttackからRELで減衰します。OFFでは連続音になります。

RGB
音域配置

B・G・Rへ低・中・高オクターブを割り当て、BGR → GRB → RBGで交代します。

TONE
音色

SIN、TRI、FM 1:1、FM 3:1、FM 3:2、FM SQRT2を順番に切り替えます。

ANALYSIS
REGION

点線の矩形が音になる範囲

左上と右下のハンドルをドラッグして位置と大きさを変更します。音量、音程、音色、発音トリガーはこの領域だけを解析します。

05

AUDIO PARAMETERS

音響スライダー

THRESH発音感度

ENV ON時だけ使用。画像変化がこの閾値以上になると再発音します。小さいほど敏感です。

REL余韻

ENV ON時のRelease時間を20〜2000msで調整します。

OCT基準音域

合成音全体を−2〜＋2オクターブ移動します。

POLY同時発音数

画像内で支配率の高い音から、最大1〜12音を選択します。

GAIN最大音量

0が基準音量、100がコンプレッサー入力で基準の10倍です。急に上げず少しずつ調整してください。

SAT彩度評価

0では高彩度を強く評価。100では反転し、白・灰色など低彩度を強く評価します。50では両者が均等です。

POLY MONITOR

12本のバーが現在選ばれている音を表示します。右側の数値は「選択中の音数 / POLY上限」です。

06

TROUBLESHOOTING

うまく動かないとき

映像が出ない

ブラウザのサイト設定でカメラを許可し、HTTPSの公開ページから開き直します。

音が出ない

SNDがONか、端末が消音状態でないか、メディア音量が上がっているかを確認します。

動作が重い

ECO ONまたはECO MAXを選び、POLY、DELAY、TRAILを小さくします。

カメラ切り替えがない

ブラウザから複数カメラを利用できない場合、REAR / FRONTボタンは自動的に隠れます。
